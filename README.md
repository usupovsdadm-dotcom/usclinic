# US CLINIC — сайт клиники пластической хирургии доктора Юсупова

Одностраничный статичный сайт: HTML + CSS + чистый JavaScript.
Сборки нет, зависимостей нет, внешних CDN нет (шрифты и картинки лежат локально).

## Структура

```
index.html            — вся разметка и тексты (разделы: hero, о докторе, услуги, до/после, цены, запись, футер)
css/style.css         — стили и анимации
js/main.js            — анимации, слайдер до/после, лайтбокс, вкладки, форма (FORM_ENDPOINT)
js/gallery-data.js    — список фото «до/после» по категориям
assets/fonts/         — Cormorant Garamond + Manrope (woff2, латиница + кириллица)
assets/img/           — фото доктора, иллюстрации услуг, логотип, иконки
assets/ba/            — фото до/после (webp + jpg, превью *-t)
assets/favicon.ico, favicon-32.png, apple-touch-icon.png, icon-512.png, og-image.jpg
```

## Размещение

Подходит любой статический хостинг: nginx/Apache, Timeweb, Beget, REG.RU, Netlify, Vercel, GitHub Pages, S3 и т.п.
Достаточно загрузить содержимое папки в корень сайта, чтобы `index.html` лежал в корне.

После размещения:
1. В `index.html` (блок `<head>`) замените `https://example.ru/` на реальный домен в `canonical`, `og:url` и `og:image`.
2. Включите HTTPS и gzip/brotli. Для `assets/` полезно задать долгий кэш.
3. Локальная проверка: `python3 -m http.server 8080` в папке сайта, затем откройте http://localhost:8080

## Форма заявки (важно)

Бэкенда нет. В `js/main.js` в самом верху есть константа:

```js
var FORM_ENDPOINT = ''; // TODO
```

Укажите URL обработчика: свой API, вебхук CRM (amoCRM, Bitrix24), Formspree, Telegram-бот и т.п.
Форма отправляет `POST` с `Content-Type: application/json`:

```json
{ "name": "...", "phone": "+7 (9xx) xxx-xx-xx", "service": "...", "consent": true, "page": "https://..." }
```

Пока `FORM_ENDPOINT` пустой, заявка никуда не уходит: пользователь видит сообщение «Спасибо», а данные пишутся в консоль браузера.
Если обработчику нужен другой формат (например `FormData`), поправьте `fetch(...)` в том же файле.

## Что ещё нужно доделать

- Ссылки на документы в футере и в согласии формы (Политика ПДн, cookie, соглашение, оферта) сейчас стоят как `href="#"` с атрибутом `data-todo`. Замените их на реальные страницы или PDF и уберите `data-todo`.
- При необходимости подключите Яндекс Метрику: вставьте её код перед `</head>`.

## Как править контент

- **Тексты** редактируются прямо в `index.html`, каждый раздел подписан комментарием.
- **Цены** есть в двух местах:
  1. в карточках услуг (`<div class="svc__price">от … ₽</div>`) в разделе `#services`;
  2. в прайсе (`<div class="prow"><span>Название</span><i></i><b>цена</b></div>`) в разделе `#prices`, по вкладкам «Грудь», «Лицо», «Веки», «Нос», «Тело», «Лазерная хирургия», «Косметология».
  Чтобы добавить строку прайса, скопируйте `div.prow`. Старая цена со скидкой пишется в `<s>…</s>`.
- **Плашка «Акция месяца»** — это `<span class="svc__badge">` внутри карточки. Удалите её или добавьте в другую карточку.
- **Фото до/после**
  1. Подготовьте пару квадратных фото одного ракурса (рекомендуется 1000×1000).
  2. Положите в `assets/ba/` файлы `ID-before.jpg`, `ID-after.jpg`, при желании ещё `.webp` и превью `ID-before-t.*` / `ID-after-t.*` (220×220).
     Если webp нет, удалите `.webp` из путей в `js/main.js` или сконвертируйте jpg в webp, например `cwebp -q 80`.
  3. Допишите строку `{ cat: "oto", id: "ID" }` в `js/gallery-data.js`.
  4. Новая категория: добавьте кнопку `<button role="tab" data-cat="новая">Название</button>` в `#baTabs` в `index.html`.
- **Фото доктора** лежат в `assets/img/hero-doctor*.{webp,jpg}` (первый экран, отдельная мобильная версия `-m`) и `doctor-portrait.*`.
- **Цвета и шрифты** задаются переменными в начале `css/style.css` (`--gold`, `--bg`, `--ink`).

## Анимации и доступность

Прелоадер, появление заголовков по словам, плавное появление блоков при прокрутке, параллакс, медленный zoom (Ken Burns) на первом экране, рисующиеся золотые линии и кольцо, бегущая строка услуг, «магнитные» кнопки с подсветкой, 3D-наклон карточек, кастомный курсор (только мышь), плавный скролл к якорям, счётчики, слайдер до/после (мышь, тач, клавиши ←/→) и полноэкранный просмотр.
Для пользователей с настройкой «уменьшить движение» (`prefers-reduced-motion`) анимации отключаются.

Служебный режим `?static=1` показывает страницу сразу, без прелоадера и анимаций. Он нужен для скриншотов.
